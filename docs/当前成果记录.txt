DBOZ汉化工具 当前成果记录
记录时间：2026-06-01

一、当前方案
- 不再做 EXE 安装器。
- 原始源文件固定放在 src_file\DBOZero。
- 开发者运行 build_output.py，在当前目录生成 output。
- 用户只拿 output 目录，自己备份游戏文件，自己复制覆盖。
- 工具不会读取或写入当前游戏目录。

三、保留文件
- build_output.py：唯一推荐入口，生成 output。
- src_file：原始源文件目录，里面放 DBOZero。
- install_hanhua.py：Taiwan/RDF 生成逻辑。
- lang0_gbk_patch.py：lang0.pak 单行 GBK 补丁逻辑。
- tbl_utf16_patch.py：tbl0.pak / tbl1.pak UTF-16LE 定长字段补丁逻辑。
- overrides.tsv：Taiwan/RDF 翻译表。
- lang0_overrides.tsv：lang0.pak 翻译表。
- tbl_overrides.tsv：tbl0.pak / tbl1.pak 翻译表。
- untranslated.tsv：查物品名、描述、表格文本用。
- tbl_candidates.tsv：查 tbl0.pak / tbl1.pak 英文候选文本用。
- 生成output流程.txt：开发者流程。

四、翻译分工
- overrides.tsv：物品名、物品描述、RDF 表格文本、Taiwan 语言文件。
- lang0_overrides.tsv：lang0.pak 里的 UI 固定词。
- tbl_overrides.tsv：tbl0.pak / tbl1.pak 里的 UTF-16LE 定长文本，适合处理新道具、新称号等 Taiwan/lang0 找不到的文本。
- obj*.pak、scr*.pak 等其他二进制资源包暂不处理。
- Taiwan 文件会先做 Windows 繁转简，再做 TAIWAN_SIMPLIFY_FIXUPS 常见残留替换，最后应用 overrides.tsv。
- 繁体残留优先处理 Taiwan 生成链路，不优先处理 lang0.pak。

五、已验证结论
- Natsu Dragneel Outfit 写入 table_text_all_data.rdf 后，游戏内显示成功。
- lang0.pak 不能整包重写。
- lang0.pak 里中文需要按 GBK/CP936 写入 value bytes。
- UTF-8 中文写入 lang0.pak 会乱码。
- GBK 单行写入 DST_ITEM_GRADE_MYTHIC=破坏 已确认游戏内显示正常。
