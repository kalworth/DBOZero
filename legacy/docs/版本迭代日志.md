# 版本迭代日志

## 2026-06-07

- 修复 `tbl1.pak` 部分装备名/道具名在游戏内显示空白的问题。原因是 `tbl1.pak` 的大量 UTF-16LE 文本带有前置长度字段，旧逻辑只替换文本并用 NUL 填充剩余空间，导致客户端按原长度读取时读到 NUL。现已在确认 `offset-2` 等于原文长度时，保持长度字段不变，并用 UTF-16 空格填充剩余空间；`tbl0.pak` 仍按固定宽 NUL 填充字段处理。
- 新增 `validate_output.py` 只读校验脚本，用于检查 `output/` 和 `output_taiwan/` 的必需文件、ANSI 编码、`tbl0.pak` / `tbl1.pak` 文件大小，以及 `tbl1.pak` 长度前缀按原长度读取时是否仍包含 NUL。
- 补充 `tbl_candidates.tsv` 中 Freeza/Frieza 相关 TBL 条目的翻译，统一译为“弗利萨”，覆盖宠物、时装、军队、残党、机器人、物品和入侵事件等相关文本。
- 暂停 `AUTO_BLOCK_TBL_VISIBLE_NAMES_20260604` 中高风险普通装备模板名的 TBL 批量补丁，已将 2100 行移入 `disabled_tbl_visible_names_20260607.tsv` 备查；保留 Freeza、Shadow、Black Dragon、Fragment、Recipe 等新内容和已验证内容，避免普通装备 tooltip 标题空白。
- 回退 `AUTO_BLOCK_LANG0_ESC_OPTIONS_20260607` 尾部块及 `lang0_gbk_patch.py` 的宽松 key 匹配改动。实测 ESC 设置菜单部分 `lang0.pak` 文本改动可能影响音效/设置逻辑，暂不纳入稳定构建。
- 修复 `lang0.pak` 变长替换导致后续元数据偏移的结构风险。`lang0_gbk_patch.py` 现改为固定长度替换，译文短于原字段时用 ASCII 空格补齐，译文超过原字段长度时直接报错；同步缩短 23 个超长 `lang0_overrides.tsv` 译文，并在 `validate_output.py` 中新增 `lang0.pak` 文件大小校验，确保输出包与源文件保持相同大小。
- 新增 `AUTO_BLOCK_LANG0_OPTION_MENU_INFO_BOT_20260608` 尾部块，集中翻译 `lang0.pak` 中主菜单、ESC Option 设置页、控制页、聊天/掉落/画面/声音/信息分页、BOT check 提示、消息框按钮、信息窗口和宠物说明等明面文本。该块位于 `lang0_overrides.tsv` 末尾，若实测有问题可整段删除；构建仍保持 `lang0.pak` 与源文件同大小。
- 新增 `AUTO_BLOCK_LANG0_POPUP_MENU_20260608` 尾部块，翻译右键玩家弹出菜单中的组队、公会邀请、交易、好友、决斗、跟随、密语、屏蔽、查看装备和取消等文本；同时恢复此前被 `#` 注释的 `lang0_overrides.tsv` 技能范围/变身提示/消息框按钮翻译行。构建和校验通过，`output/` 与 `output_taiwan/` 的 `lang0.pak` 均保持固定大小。
- 修复 `lang0.pak` 短译文在 Option、右键菜单等 UI 控件中对齐混乱的问题。`lang0_gbk_patch.py` 现在仍按原字段容量保持文件大小，但会把固定长度补齐空格写到结束引号外，使游戏实际读取的字符串不再包含尾部空格；同时移除右键菜单翻译中此前用于临时居中的手工前置空格，并在 `validate_output.py` 中新增 `lang0` 逐条实际字符串校验。
- 新增 `AUTO_BLOCK_LANG0_LONG_TEXT_20260608` 尾部块，翻译登录进入游戏排队提示 `DST_LOBBY_WAIT_GAME_SERVER_CONNECT`、BOT 登录验证提示 `DST_SCS_LOGIN_ALERT`、传送确认弹窗 `DST_TELEPORT_COMMON_CONFIRM_MSG` 及其 Yes/No 按钮、倒计时时间/秒单位。该类 `lang0.pak` 长文本保留 `[align]`、`[font]`、`[br]` 富文本标记和 `%d` / `%s` 占位符，只替换可见文本；构建时继续按固定字段长度校验，避免破坏 `lang0.pak` 结构。
